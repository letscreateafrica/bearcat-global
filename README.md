# Bearcat Global

Independent Student Rights & Opportunity Brief for African, Pakistani, Chinese and Indian undergraduate, graduate and PhD students at Southwest Baptist University.

## Complete project

Download and extract **Bearcat-Global-Final-Project.zip**. It contains the entire project, including Node build/check/preview scripts, content.json, dated HTML pages, full-text briefs, CSS/JavaScript, Python cover compositor, original illustration, official SBU logo, every finished visual, hosting manifest and editorial instructions. No credentials, private student records or Git metadata are included. Directory structure is preserved inside the archive.

After extraction, follow the included README.md. To rebuild pages run `node build.mjs`, then `node verify.mjs`. Recompose covers with `python artwork/compose_heroes.py` (Pillow required).
